# Dashboard Design and Wireframe

## 1. Overview

The project uses Plotly Dash to provide an interactive dashboard for nationwide retail demand forecasting and inventory optimization.

The dashboard presents forecasting results, model evaluation metrics, prediction intervals, and inventory replenishment recommendations.

## 2. Dashboard Pages

### Page 1: Executive Overview

Displays key performance indicators:

- Total forecast demand
- WAPE
- RMSSE
- Inventory reorder alerts

### Page 2: Demand Forecasting

Visualizes:

- Historical sales
- Predicted demand
- Actual versus predicted values
- Upper and lower prediction intervals

Includes store, department, category, product, and date filters.

### Page 3: Model Performance

Compares the following forecasting models:

- Naive
- Prophet
- LightGBM
- Temporal Fusion Transformer

Evaluation metrics:

- WAPE
- RMSSE

### Page 4: Inventory Optimization

Displays:

- Available inventory
- Forecast demand
- Safety stock
- Recommended reorder quantity
- Expected shortages
- Inventory recommendations

## 3. Technology

- Python
- Plotly
- Dash
- Pandas
- Google OR-Tools

## 4. Dashboard Data Flow

Forecast outputs and evaluation results are loaded into the dashboard.

The dashboard visualizes these results and presents inventory recommendations generated by the optimization module.

## 5. Design Principles

- Clean and professional interface
- Interactive filters
- Clear KPI presentation
- Consistent chart styling
- Easy-to-understand inventory recommendations
